# R.E.P.O. - Discover All Rooms

Allows you to set all rooms as discovered and reveal them on the map. Compatible with most other mods.

## Installation
1. Download & install [BepInEx](https://github.com/BepInEx/BepInEx).
2. Download the [latest release](https://github.com/Nixeld/R.E.P.O.-Discover-All-Rooms/releases) of this mod.
3. Extract `Nixeld-DiscoverAllRooms.zip` into your `BepInEx/plugins` directory.

Alternatively, the mod is available via the [Thunderstore Mod Manager](https://thunderstore.io/c/repo/p/Nixeld/DiscoverAllRooms/).

## Configuration

Settings can be configured in-game using the [REPOConfig mod](https://thunderstore.io/c/repo/p/nickklmao/REPOConfig/), or manually by:

1. Launch the game with mod installed at least once.
2. Edit the `Nixeld.DiscoverAllRooms.cfg` file within your `BepInEx/config` directory.

<details>
<summary>Example Configuration</summary>

```
## Settings file was created by plugin DiscoverAllRooms v1.0
## Plugin GUID: Nixeld.DiscoverAllRooms

[General]

## When enabled, all rooms are revealed on the map at the start of each level.
# Setting type: Boolean
# Default value: true
DiscoverAllRooms = true

```

</details>
